# BoketeImageAnnotator の「どれもなし」の問題での定義の表示

## 1. 概要

order_035 では，画像の要素の問題で表示したラベルの項目の定義のみを示すようにしたため，ラベルが「空欄・カルタ記号・文字のどれもなし」の問題では定義が1つも示されなかった．この問題では評価者は3項目の全てがないことを確かめる必要があり，定義がないと文字などの見落としが増えるおそれがある．そこで，「どれもなし」の場合に限り，空欄，カルタ記号，文字の3項目の定義を全て示すようにした．それ以外の値は表示した項目の定義のみを示す．表示が変わったため，表示の版（`UI_VERSION`）を4に上げた．

| 項目 | 内容 |
| :--- | :--- |
| 変更 | `src/messages.ts`（`definitionText`），`src/labels.ts`（`UI_VERSION = 4`） |
| 確認 | vitest 14件，型の検査，模擬試験（全項目合格．回答の表示の版が4であることを確認） |
| コミット | `cbc0f6d` |

## 2. 表示の文字数

画像の要素の問題の吹き出しに示す文（軸の注意を含む）の文字数を表に示す．「どれもなし」のみ22字から126字に増え，他の値は版3と同じである．

| 画像の要素のラベル | 版2 | 版3 | 版4 |
| :---: | :---: | :---: | :---: |
| どれもなし | 151 | 22 | 126 |
| 文字 | 151 | 75 | 75 |
| 空欄＋文字 | 151 | 105 | 105 |
| 空欄＋カルタ記号＋文字 | 151 | 126 | 126 |

## 3. 未解決の論点と次の作業の候補

- 「どれもなし」以外の値（例「文字」）でも，表示していない項目（空欄，カルタ記号）の見落としは起こりうる．版4の回答が集まった後に，値ごとの「一致する」の割合を版2と比べ，見落としの傾向を確かめる必要がある．
- 新しい表示は動作中の `npm run image:tunnel` を再起動するまで反映されない．実際の LINE の画面での表示は未確認である．
- 集計で版4の回答のみに絞るには `export_results.py --ui-version 4` を用いる．
