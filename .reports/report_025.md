## 3. 数値の扱い

各実験の報告では，その時点の目視ラベルで評価していたため，正解が実験ごとに少しずつ異なっていた．
論文では比較をそろえるため，ex014〜ex017 の主な方法の予測を，ex016 の合意ラベル（620件）で評価し直した（`programs/ex018_paper_boke/unified_eval.py` → `outputs/ex018_paper_boke/unified.csv`）．

- 第1版の検証データ（420件）だけで評価した ex013 の結果は，評価し直せない．そのため，当時の目視ラベルでの値であることを明記して記載した．
- 論文の新しい図（段階ごとの F1，教師の指示，学習曲線）は，`programs/ex018_paper_boke/make_figures.py` で作った．画像外の知識と速度の図は ex017 の図を用いた．
- 論文の本文の主な数値は，unified.csv と各実験の出力に照らして確かめた．執筆中に見つけて直した誤りは次のとおりである．
  - 再現性の「6区分の約2割」を「約14%（一致率0.86）」に直した．
  - 画像外の知識の判断の揺れは「約7%」とした（620件中42件）．
  - Qwen3-VL-2B（目視ラベルのみ）の調整用の値を0.69 に直した．
  - 段階2による改善の幅を「0.12〜0.16」に直した．

## 4. 未解決の論点（論文の改訂の候補）

1. **目視ラベルの判断者：** 全て Claude Code によるラベルであり，人の判断者との一致は測っていない．論文では限界として明記した．査読では最も強く指摘されうる点であり，人のラベル（一部でもよい）があると論文の価値が大きく上がる．
2. **全件への適用の結果がない：** 方法の確立までで，全件のラベルの分布や，下流の生成・判定での有用性は示していない．お題画像の論文（`paper/`）には全件の分布の章がある．全件に適用した後に1章を加えることを勧める．
3. **画像外の知識の図：** ex017 の図（fig_outside.png）を流用している．文字が小さいため，論文用に PDF で作り直す余地がある．
4. **一覧の例の画像：** 図1はボケてのお題画像とボケを含む．投稿先によっては，転載の扱いを確認する必要がある．
5. **分量：** 12ページである．投稿先が決まったら，ページ数の制限に合わせて第7章（第1版の比較）や表を調整する．
6. **関連研究：** 大喜利・ユーモアの研究は2件のみを挙げた．発話の型（セリフ・ツッコミなど）に関する言語学やお笑いの研究の引用を加えると，ラベルの設計の位置づけが明確になる．
