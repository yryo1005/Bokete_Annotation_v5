# お題画像のラベル定義（第4版）

BoketeDBv5 でお題画像に付与するラベルの定義である．形式，属性，媒体の3つの軸からなる．
評価用ラベルの付与と VLM のプロンプトは，本定義に従う．

## 1. 形式（1つ選択）

ユーザーの回答を制限する画像である．以下の順に判定し，最初に当てはまったものとする．

1. カルタ：ひらがな1文字が入った記号（○，□など）がある画像．ひらがなから始まる大喜利を投稿する．ひらがなは文の一部ではなく，独立した記号（枠）の中にあるものに限る．空欄も含む場合もカルタとする．
2. 穴埋め：語の代わりに置かれた空欄（矩形，○，吹き出しなど）がある画像．空欄に入る大喜利を投稿する．○○，□，＿＿，語の代わりの「？」，語の代わりに置かれた黒塗り（顔や個人情報の目隠しは除く），話者に付いた空の吹き出しを含み，文末の疑問符は含まない．お題文も含む場合も穴埋めとする．
3. お題文：問いや指示の文がある画像．問いや指示に対応した大喜利を投稿する．問い（〜とは？），指示（〜してください）に加え，題目の句（〜あるある，〜な事，〜の共通点），状況の設定（〜なのに…），名前などの列挙を含む．字幕，看板，台詞のように画像に元からある文字は含まない．投稿者が書き加えた文字（ボケてのテンプレートの枠内の文字，無地の背景に置いた文字，画像の上下に付け足した文字）はお題文の候補とし，テレビの字幕，看板，商品の表示，漫画の台詞は元からある文字とする．名前などの列挙は投稿者が書き加えたものに限る．テロップ，字幕，看板など投稿者が重畳したのではない文は，問いの形をしていてもお題文ではなく，属性の「文字あり」で表す．テロップ等の中に空欄がある場合は穴埋めとする．ボケてのテンプレートの枠内や無地の背景に投稿者が書いた文が画像の主題である場合（台詞，題名，主張の文，詩などを含む）は，問いの形でなくてもお題文とする（回答者はその文を読んで大喜利を作るため）．ただし，ニュースの記事，ウェブやアプリの画面，テレビの字幕など，元からある文章を写したものは除く．空欄を含む文そのものはお題文とせず，空欄とは別に問いや指示の文がある場合のみ「お題文あり」とする．
4. 通常：上記の形式以外の画像．

形式は実際の大喜利とペアで決定するものであるが，画像の投稿者の意図をくみ取り決定する．形式は投稿者の意図を優先し，ボケの傾向（カルタの書き出しの集中度など）や `type` 列は判定の証拠として用い，意図と食い違う場合は見直しの対象とする．

## 2. 属性（複数選択）

- 空欄あり
- カルタ記号あり
- 文字あり：読める文字がある（お題文，テロップ，字幕，看板，台詞，効果音の描き文字，商品の表示，衣服やユニフォームの文字，ロゴ，透かし，著作権表示，日付の写し込みなどを含む）．ぼかしやモザイクで読めない文字，判読できないほど小さな文字は除く．カルタ記号のひらがな1文字だけの場合は文字なしとする

文字が大喜利に影響しているか（文字を読んで大喜利を作るか）は，画像のラベルでは扱わず，ボケの文章を見て判断する．画像のラベルの「文字あり」は，その判断の対象とする画像を絞るための目印である．投稿者が重畳したお題文は，引き続き形式の「お題文」で表す．

## 3. 媒体（原則として1つ選択．合成画像で異なる媒体の領域がある場合のみ複数選択）

画像のスタイルである．画像の面積の約2割以上を占める領域の媒体を付ける．

- 写真：現実の写真（実写の映像，フィギュアや人形，着ぐるみ，像を撮影したものを含む）
- アニメ：アニメのスクリーンショット
- ゲーム：ゲーム画面のキャプチャ
- マンガ：漫画作品から切り抜いたコマ（枠線，スクリーントーン，写植の台詞などをもつ．漫画風の一枚絵や吹き出し付きのカットはイラスト）
- テキストグラフィック：文字や記号が主体で，写真や絵がほとんどない画像（ウェブページやアプリの画面を含む）
- 絵画：古典的絵画（浮世絵などの版画を含み，写真に撮ったものも絵画とする）
- イラスト：上記に含まれない絵（アニメや漫画のキャラクターの描き下ろし，模写，漫画風の一枚絵，カルタの札の絵，手描きの絵を含む）

3DCG や生成AIによる画像は，同じ見た目の画像を人が作った場合の媒体とする（写実的なものは写真，ゲームの画面はゲーム，アニメの画面を模したものはアニメ，それ以外はイラスト）．

合成画像（複数の画像の貼り合わせ，写真と絵の重ね合わせ）は，各領域の媒体を複数選択することで表す．

## 改訂履歴

- 第2版：テロップ等の扱いを明記し，空欄を含む文の扱いを定めた．事前知識の軸を廃止した．
- 第3版：属性の合成画像を削除し，お題文ありとその他の文字ありを「文字あり」に統合した．媒体の CG を削除し，3DCG と生成AIの画像は見た目で振り分けることとした．マンガの定義に例示を加えた．
- 第4版：「文字あり」を，ロゴ，透かし，著作権表示，看板，衣服の文字なども含め，読める文字があれば真とするように変えた．文字が大喜利に影響しているかは，ボケの文章を見て判断することとした．
- 第4版の補足：ボケてのテンプレートや無地の背景に投稿者が書いた主題の文は，問いの形でなくてもお題文とすることを明記した．
