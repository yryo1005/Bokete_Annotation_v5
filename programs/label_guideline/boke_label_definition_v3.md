# 大喜利（ボケ）のラベル定義（第3版）

お題画像に投稿されたボケに付けるラベルの定義である．
ボケのラベルは，お題画像のラベル（label_definition_v4.md の形式・属性・媒体）を前提とし，次の4つの項目からなる．
ラベルはボケの文とお題画像を見て付ける．ボケの評価（面白さ）は扱わない．

## 1. 制約の順守（はい／いいえ／対象外）

お題の形式が課す制約に，ボケが従っているかである．

- カルタ：ボケの書き出しが，札のひらがなと同じ音で始まる．漢字やカタカナで始まる場合は読みで判断する（例：「ふ」の札に「冬服が」は順守）．括弧や記号は飛ばす．
- 穴埋め：ボケが空欄に入る語句である（空欄の語句のみ，または空欄を埋めた文全体のいずれでもよい）．
- お題文：ボケがお題文の問いや指示に応じている．
- 通常：対象外とする．

お題と無関係な文（宣伝，他のボケへの返信，サイトへの書き込みなど）は，形式によらず「いいえ」とする．

## 2. 発話の型（6区分と3区分の両方を持つ）

ボケが，誰の視点の，どのような言葉であるかである．6区分を付け，そこから3区分を導く．
6区分は人でも判断が分かれやすく（特にセリフ・心の声・ツッコミの境界），自動判定の精度も低いため，信頼性の低いラベルとして扱う．
3区分は，生成の条件や全件の集計に用いる．

### 2.1 6区分（1つ選択．判定の手順）

次の問いを順に確かめる．

1. 形式が穴埋め・お題文で，ボケが空欄や問いへの答えである → 回答
2. ボケが名詞句（体言止め）で，画像全体や写っている物に名前・題・例えを付けている（「〜の時の俺」「〜界の〜」を含む） → 名付け・見立て
3. ボケの話し手が，画像の中の人物・動物・物（擬人化を含む）である
   - 声に出している（呼びかけ，返事，叫び，掛け合い，相手のいる言葉） → セリフ
   - 心の中の考え，独り言（括弧書き，「…かな」「…しよう」など） → 心の声
   - 迷う場合はセリフとする
4. ボケの話し手が，画像の外の人である
   - 画像の出来事を説明する文，前後の出来事・状況の設定（「〜したら〜だった」「〜する様子」「〜の結果」） → 状況の説明・物語
   - 画像を見て言う感想・指摘・ツッコミ，画像の人物への呼びかけ（「〜すぎる」「〜じゃん」） → ツッコミ・呼びかけ

カルタのボケは，文の形に応じて2〜4のいずれかとする．

### 2.2 3区分

| 3区分 | 6区分 |
| :--- | :--- |
| 登場人物の言葉 | セリフ，心の声 |
| 外からの言葉 | ツッコミ・呼びかけ，状況の説明・物語，名付け・見立て |
| 回答 | 回答 |

## 3. 画像外の知識（はい／いいえ）

ボケの面白さを理解するのに，**画像にも画像中の文字にも示されていない，特定の事物についての知識**が必要かである．
「その事物を知らない人は，一般的な日本語の語彙と生活の常識があっても，ボケの面白さが分からない」場合に「はい」とする．
固有名詞をモデルが言い当てられるかどうかではなく，ボケが何に依存しているかで判断する．

### 3.1 「はい」とする条件（3つ全てを満たす）

1. **特定性**：ボケが依存しているのが，特定の作品・キャラクター・人物・団体・商品・ブランド・番組・CM・歌・映画・ゲーム・地名（その土地の印象）・
   出来事・ニュース・流行語・ネットの定型（ミーム）・有名な台詞・キャッチコピー・ボケての機能や慣習のいずれかである．
2. **画像の外**：その事物が，画像に写っておらず，画像中の文字（お題文，看板，題名など）でも名指しされていない．
   画像に写っている人物やキャラクター自身の設定・経歴を使うボケは「いいえ」とする（画像中のオブジェクトの情報であり，画像外ではない）．
3. **必要性**：その事物を知らないと，ボケの面白さ（言葉遊び，パロディ，連想）が成り立たない．事物の名前が出てくるだけで，知らなくても
   面白さが分かる場合は「いいえ」とする（例：「渋谷も大したことないな」は渋谷を知らなくても意味が通るが，渋谷の印象を使っているため「はい」．
   一方，「ディズニーランドで迷子になった」のように場所の名前が背景にすぎない場合は「いいえ」）．

### 3.2 「いいえ」とするもの

- 画像の見た目とボケの字面だけで分かるもの
- 一般の語彙，慣用句，ことわざ，ダジャレの元の語，誰もが経験する生活の事物や行事（ラジオ体操，だるまさんがころんだ，給食，満員電車など，
  特定の作品や商品ではない一般的なもの）
- 画像に写っている，または画像中の文字で名指しされた事物の知識（例：ドラえもんの画像に，ドラえもんの道具を使うボケ）
- 一般的な職業・役割・ジャンル（警察官，ヤンキー，時代劇，ホラー映画）の典型的な印象

### 3.3 判定の手順

1. ボケが依存している事物を書き出す（なければ「いいえ」）．
2. それが特定の事物か，一般的な事物かを判断する（一般的なら「いいえ」）．
3. それが画像に写っているか，画像中の文字で名指しされているかを確かめる（そうなら「いいえ」）．
4. それを知らない人に面白さが伝わるかを考える（伝わるなら「いいえ」，伝わらないなら「はい」）．

検証データの分析のためには，参考として第2版の4段階（見た目だけ，一般常識，画像中のオブジェクト，画像外）も残す．

## 4. 画像中の文字への依存（はい／いいえ）

ボケの意味や面白さが，画像中の文字（お題文，穴埋めの文，字幕，看板，漫画の台詞，カルタの札の文字そのものへの言及）を読まないと分からない場合に「はい」とする．
カルタの札のひらがなで始まることだけでは「はい」としない．

- 第2版：性的・不適切の項目を除いた．必要な知識を，上から順に判定する手順として定義し直した．
