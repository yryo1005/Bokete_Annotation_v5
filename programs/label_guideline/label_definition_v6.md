# お題画像のラベル定義（第6版の草案）

BoketeDBv5 でお題画像に付与するラベルの定義の草案である．第5版の属性と媒体の軸は変えず，「文字あり」を文の属性（文字の層と文の形）に細分化する．
お題文ありは，第5版では「お題の投稿者が回答者に向けて書き加えた文」として付与していた．これは投稿者の意図に依存し，画像から判定できない場合があるため，第6版では付与せず，文の属性から規則で導く．
誰が書いたか，題のつもりか台詞のつもりか，既存の歌詞や台詞の引用かは記録しない．第5版は [label_definition_v5.md](label_definition_v5.md) に残す．

## 1. 属性（複数選択）

カルタ記号あり，空欄あり，文字ありは第5版と同じである．お題文ありは4節の規則で導く．

- カルタ記号あり：ひらがな1文字が入った記号（○，□など）がある．ひらがなは文の一部ではなく，独立した記号（枠）の中にあるものに限る．
- 空欄あり：語の代わりに置かれた空欄（矩形，○，吹き出しなど）がある．○○，□，＿＿，語の代わりの「？」，語の代わりに置かれた黒塗り（顔や個人情報の目隠しは除く），話者に付いた空の吹き出しを含み，文末の疑問符は含まない．
- 文字あり：読める文字がある（第5版と同じ）．文字の層（2節）のどれかが真なら真である．

## 2. 文字の層（軸A，複数選択）

画像の中の読める文字が，どこにどう書かれているかである．見た目で判定する．

- 場面の文字：写っている世界の中にある文字．看板，ポスター，商品や衣服の表示，本・CD・DVD の表紙，黒板やホワイトボード，写真に写った画面の表示，ウェブページ・SNS・アプリ・ゲームのスクリーンショットの画面の中の文字，漫画やイラストに描き込まれた効果音や看板を含む．透かし，ロゴ，署名，著作権表示，日付の写し込み，ボケてのテンプレートに印刷された定型の見出し（「写真で一言ボケて」）も，位置によらずここに含める．
- 吹き出し：漫画やイラストの吹き出しと語りの枠（ナレーションの枠）の中の文字．吹き出しのない，絵の中の人物の脇に描き込まれた台詞（漫画の台詞，スタンプの絵の台詞）を含む．話者に付いた空の吹き出しは空欄であり，文字ではない．
- 重ねた文字：写真や絵の上に重ねた文字．テレビの字幕やテロップ，写真に書き込んだ文字，画像の上に置いた文字の帯（下地が半透明で絵が透けるもの）を含む．元の放送の字幕か投稿者が加えたものかは問わない．
- 余白の文字：写真や絵の外にある文字．画像の上下左右の帯や枠，無地の背景，ボケてのテンプレートの文字欄に書いた文字．写真や絵がほとんどない画像で，文字が主体のもの（スクリーンショットを除く）の文字もここに含める．

判定の要点：

- 写真や絵の領域の上にあれば重ねた文字，外（帯，枠，背景）にあれば余白の文字である．帯の下地が不透明で絵を隠している場合は余白の文字とする．
- スクリーンショットは画面そのものが素材であるため，画面の中の文字は場面の文字とする．スクリーンショットの外に加えた帯や，画面の上に重ねた文字は，それぞれ余白の文字，重ねた文字とする．

## 3. 文の形（軸B，層ごとに複数選択）

重ねた文字と余白の文字について，それぞれの層にどの形の文があるかを記録する．場面の文字と吹き出しの文の形は記録しない．
文の形は文面で判定し，誰の言葉か，題として書いたかは問わない．

- 空欄を含む文：空欄を含む文と，空欄を含む文章のまとまり（段落，説明文，記事，字幕，歌詞，引用，台詞，台本，折句）．まとまりは，空欄のない文を含んでいても全体をこの形とする．「X vs （　）」「○○警察」のように題そのものに空欄を含むもの，題目のない列挙の最後を空欄にしたものもこの形とする．
- 問い：疑問の形の文（〜とは？，〜なのはなぜ？，どっち派？，何と言った？）．「もし〜たら」「〜したら」で始まる条件の形の文もここに含める．
- 指示：回答者への依頼や命令の形の文（〜してください，〜を教えて下さい，一言ボケて，〜しろ）．
- 題目の句：大喜利の題となる名詞句や定型の句（〜あるある，〜ないない，〜な事，〜の共通点，こんな〜は嫌だ，〜する方法，〜ランキング，〜の特徴）．題目の後に例を列挙したものを含む．
- その他の文：上記のどれでもない文や語句（平叙文，台詞，感想，状況の説明，題名，名前，項目の名札，分類やシリーズの名札だけの見出し（「なぞかけ」「【問題】」）など）．

判定の要点：

- 空欄を含む文の判定を先に行う．空欄を含むまとまりの中の問いや指示は，問いや指示としない．
- 空欄を含むまとまりとは別に，問い・指示・題目の句の文がある場合は，両方の形を真とする（「世の中で弱いものは？ 1位 赤ちゃん … 523位 □」は問いと空欄を含む文）．
- 話者を付けた台本（「娘『〜？』パパ『□』」）は，空欄を含めば空欄を含む文，含まなければその他の文とする．台本の中の問いの形の台詞は問いとしない．
- 文末が「？」でも，語の代わりに置かれた「？」は空欄である．

## 4. お題文ありの導き方

お題文ありは，文の属性から次の規則で導く．規則の選択肢は，属性を付け直さずに変更できる．

既定の規則（R1b）：重ねた文字または余白の文字に，問い・指示・題目の句のどれかがある．または，余白の文字にその他の文があり，同じ余白の文字に空欄を含む文がない．

- 重ねた文字の問い・指示・題目の句は，元の放送の字幕か投稿者が加えたものかによらずお題文ありとする．投稿者が写真に重ねた問いと元の字幕の問いは見た目で区別できず，どちらを除いても一方を誤るためである．
- 余白に空欄を含む文がある場合，その他の文（名前，項目の名札，題名，「なぞかけ」などの見出し）は空欄を埋めるための見出しとみなし，根拠にしない．空欄の文とは別に置いた状況の文も根拠にならないが，問い・指示・題目の句の形であれば第1の条件でお題文ありとなる．

規則の選択肢：

- R0：重ねた文字または余白の文字に，問い・指示・題目の句のどれかがある（余白のその他の文を含めない）．
- R1：R0 に，余白の文字のその他の文を，空欄を含む文の有無によらず加える．
- R2：R1 に，重ねた文字のその他の文を加える．

第5版との主な違いは次のとおりである．

- 重ねた文字の問い・指示・題目の句は，元の放送の字幕であってもお題文ありとなる（第5版では元の素材の字幕はお題文なし）．
- 余白の文字に書き写した既存の歌詞や台詞は，空欄を含む文がなければお題文ありとなる（第5版ではお題文なし）．
- 重ねた文字の台詞や状況の説明は，お題文なしとなる（第5版では投稿者が加えた状況の文ならお題文あり）．
- 余白の文字で空欄を含む文と並ぶ状況の文は，問い・指示・題目の句の形でなければお題文なしとなる（第5版ではお題文あり）．
- 場面の文字と吹き出しの文は，形によらずお題文ありとならない．

## 5. 媒体

第5版と同じである．

## 6. 形式（属性から導く）

第5版と同じく，カルタ記号あり → カルタ，空欄あり → 穴埋め，お題文あり → お題文，それ以外 → 通常の順に導く．

## 改訂履歴

- 第6版（草案）：お題文ありを付与する属性から外し，文字の層（軸A）と，重ねた文字・余白の文字の文の形（軸B）から規則で導くこととした．誰が書いたか，題のつもりか，引用かを判定に用いないこととした．既定の規則を R1b とし，重ねた文字の問いを元の字幕であってもお題文ありに含めることとした（order_045）．

## 付録：目視のラベルの書式（実験 ex026）

1行に1枚の画像を「番号 ラベル [メモ]」で記す．ラベルは層の記号を「,」で区切ったものとし，重ねた文字と余白の文字には「:」の後に文の形の記号を続ける．文字がない場合は「-」とする．

| 記号 | 意味 |
| :--- | :--- |
| s | 場面の文字 |
| b | 吹き出し |
| o | 重ねた文字 |
| m | 余白の文字 |
| k | 空欄を含む文 |
| q | 問い |
| i | 指示 |
| t | 題目の句 |
| x | その他の文 |

例：`12 s,o:x,m:qk`（場面の文字，重ねた文字にその他の文，余白の文字に問いと空欄を含む文）．
