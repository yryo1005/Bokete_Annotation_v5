# お題画像のラベル定義（第5版）

BoketeDBv5 でお題画像に付与するラベルの定義である．属性と媒体の2つの軸を付与し，形式は属性から導く．
評価用ラベルの付与と VLM のプロンプトは，本定義に従う．第4版は label_definition_v4.md に残す．

## 1. 属性（複数選択）

- カルタ記号あり：ひらがな1文字が入った記号（○，□など）がある．ひらがなは文の一部ではなく，独立した記号（枠）の中にあるものに限る．
- 空欄あり：語の代わりに置かれた空欄（矩形，○，吹き出しなど）がある．○○，□，＿＿，語の代わりの「？」，語の代わりに置かれた黒塗り（顔や個人情報の目隠しは除く），話者に付いた空の吹き出しを含み，文末の疑問符は含まない．
- お題文あり：お題の投稿者が回答者に向けて書き加えた，大喜利の題となる文がある．空欄やカルタ記号の有無と独立に判定する（2節）．
- 文字あり：読める文字がある（お題文，テロップ，字幕，看板，台詞，効果音の描き文字，商品の表示，衣服やユニフォームの文字，ロゴ，透かし，著作権表示，日付の写し込みなどを含む）．ぼかしやモザイクで読めない文字，判読できないほど小さな文字は除く．カルタ記号のひらがな1文字だけの場合は文字なしとする．

属性の間の関係：お題文ありなら文字ありとする．文字が大喜利に影響しているか（文字を読んで大喜利を作るか）は，画像のラベルでは扱わず，ボケの文章を見て判断する．

## 2. お題文ありの判定

### 2.1 含むもの

- 問い（〜とは？，〜なのはなぜ？，どっち派？）と指示（〜してください，〜を教えて下さい，一言ボケて）
- 題目の句（〜あるある，〜ないない，〜な事，〜の共通点，こんな〜は嫌だ，〜する方法，〜ランキング）．題目の後に例を列挙し，最後の項目を空欄にしたものを含む
- 状況の設定や短い筋書き（もし〜が来たら，〜したら世界が滅びました）
- ボケてのテンプレート，無地の背景，画像の上下の帯に投稿者が書いた主題の文．問いの形でなくてもよい（台詞の書き出し，主張の文，題名，手紙の書き出し，定型句を含む）
- 投稿者が素材に加えた問いの枠やテロップ（漫画のコマの下に加えた「〜が見たものとは!?」など）

### 2.2 含まないもの

- 空欄を含む文そのもの．空欄を含む文章のまとまり（段落，説明文，記事，字幕やテロップ，歌詞，引用，台詞，台本，折句）は，空欄のない文が含まれていても全体を空欄を含む文とみなす
- 話者を付けた台本（「娘『〜？』パパ『□』」，「記者：〜を教えてください」と空の吹き出し）．問いの形の台詞を含んでいても，場面の中の台詞とみなす
- 「X vs （　）」，「○○警察」のように，題そのものに空欄を含むもの
- 題目のない列挙の最後を空欄にしたもの（「①休みたい ②ひらめいた ③」）
- 分類やシリーズの名札だけの見出しと，空欄を含む文の組（「ことわざ『善は□』」，「なぞかけ」，「【問題】」，「ベタベタお題シリーズ」）
- 元の素材にある文字：テレビの字幕やテロップ，看板，ポスター，本・CD・DVD の表紙，商品，広告，ウェブの記事やコメント，SNS やアプリの画面，ゲーム・アニメ・漫画の台詞，歌詞，有名な台詞の引用，人物やものの説明文
- 既存の歌詞，詩，有名な台詞を書き写したもの（無地の背景やテンプレートに書いたものを含む）
- 絵の中の吹き出しや，人物の脇に書かれた登場人物の台詞．写真やアニメの画像に付けた，人物の台詞や感想の字幕（「おやすみなさい」）
- ボケてのテンプレートに印刷された定型の見出し（「写真で一言ボケて」）

### 2.3 空欄やカルタ記号と同時に付く場合

空欄とは別の文として問い・指示・題目・状況の文がある場合に，空欄ありと同時にお題文ありとする．例：「世の中で弱いものは？ 1位 赤ちゃん … 523位 □」，「初めて○○に来た△△様!! 最初に放った一言とは…!?」と空の吹き出し，「空欄で顔を作って下さい．」と空欄で描いた顔，「リオって？」と回答欄．
題目の句が見出しで，その下に空欄を含む文が続く場合（「ウサギをなつかせる方法 □をあげる」）もお題文ありとする．

## 3. 媒体（原則として1つ選択．合成画像で異なる媒体の領域がある場合のみ複数選択）

画像のスタイルである．画像の面積の約2割以上を占める領域の媒体を付ける．

- 写真：現実の写真（実写の映像，フィギュアや人形，着ぐるみ，像を撮影したものを含む）
- アニメ：アニメのスクリーンショット
- ゲーム：ゲーム画面のキャプチャ
- マンガ：漫画作品から切り抜いたコマ（枠線，スクリーントーン，写植の台詞などをもつ．漫画風の一枚絵や吹き出し付きのカットはイラスト）
- テキストグラフィック：文字や記号が主体で，写真や絵がほとんどない画像（ウェブページやアプリの画面を含む）
- 絵画：古典的絵画（浮世絵などの版画を含み，写真に撮ったものも絵画とする）
- イラスト：上記に含まれない絵（アニメや漫画のキャラクターの描き下ろし，模写，漫画風の一枚絵，カルタの札の絵，手描きの絵を含む）

3DCG や生成AIによる画像は，同じ見た目の画像を人が作った場合の媒体とする（写実的なものは写真，ゲームの画面はゲーム，アニメの画面を模したものはアニメ，それ以外はイラスト）．
合成画像（複数の画像の貼り合わせ，写真と絵の重ね合わせ）は，各領域の媒体を複数選択することで表す．

## 4. 形式（属性から導く）

形式は付与せず，属性から次の順に導く．最初に当てはまったものとする．第4版の形式と同じ優先順位である．

1. カルタ：カルタ記号あり
2. 穴埋め：空欄あり
3. お題文：お題文あり
4. 通常：上記のどれもない

## 改訂履歴

- 第2版：テロップ等の扱いを明記し，空欄を含む文の扱いを定めた．事前知識の軸を廃止した．
- 第3版：属性の合成画像を削除し，お題文ありとその他の文字ありを「文字あり」に統合した．媒体の CG を削除し，3DCG と生成AIの画像は見た目で振り分けることとした．マンガの定義に例示を加えた．
- 第4版：「文字あり」を，ロゴ，透かし，著作権表示，看板，衣服の文字なども含め，読める文字があれば真とするように変えた．文字が大喜利に影響しているかは，ボケの文章を見て判断することとした．ボケてのテンプレートや無地の背景に投稿者が書いた主題の文は，問いの形でなくてもお題文とすることを明記した．
- 第5版：形式を付与する軸から外し，属性から導くこととした．属性に「お題文あり」を加え，空欄やカルタ記号の有無と独立に付けることとした（第4版では，穴埋めやカルタの画像にある問いや指示の文は記録されなかった）．空欄を含む文章のまとまり，話者を付けた台本，名札だけの見出し，絵の中の台詞の扱いを明記した．既存の歌詞や詩を無地の背景に書き写したものは，第4版ではお題文の候補であったが，第5版ではお題文なしとした．
