# 大喜利（ボケ）のラベル定義（第2版）

お題画像に投稿されたボケに付けるラベルの定義である．
ボケのラベルは，お題画像のラベル（label_definition_v4.md の形式・属性・媒体）を前提とし，次の4つの項目からなる．
ラベルはボケの文とお題画像を見て付ける．ボケの評価（面白さ）は扱わない．

## 1. 制約の順守（はい／いいえ／対象外）

お題の形式が課す制約に，ボケが従っているかである．

- カルタ：ボケの書き出しが，札のひらがなと同じ音で始まる．漢字やカタカナで始まる場合は読みで判断する（例：「ふ」の札に「冬服が」は順守）．括弧や記号は飛ばす．
- 穴埋め：ボケが空欄に入る語句である（空欄の語句のみ，または空欄を埋めた文全体のいずれでもよい）．
- お題文：ボケがお題文の問いや指示に応じている．
- 通常：対象外とする．

お題と無関係な文（宣伝，他のボケへの返信，サイトへの書き込みなど）は，形式によらず「いいえ」とする．

## 2. 発話の型（1つ選択）

ボケが，誰の視点の，どのような言葉であるかである．

1. セリフ：画像内の人物・動物・物（擬人化を含む）が話す言葉．複数の登場人物の掛け合いを含む．
2. 心の声：画像内の人物などの考えや独り言（口に出していない言葉）．
3. ツッコミ・呼びかけ：画像を見ている側の感想，指摘，画像内の人物への呼びかけ．
4. 状況の説明・物語：画像の前後の出来事や，画像の状況を説明する文（「〜したら〜だった」「〜している様子」）．
5. 名付け・見立て：画像全体や写っている物に名前や題を付ける，別の物に例える．「〜の時の俺」「〜界の〜」を含む．名詞句で終わることが多い．
6. 回答：お題文の問いや，穴埋めの空欄への答え．カルタのボケは，文の形に応じて1〜5のいずれかとする．

セリフか心の声かは，口に出しているか（呼びかけ，相手のいる言葉か）で判断し，迷う場合はセリフとする．

## 3. 必要な知識（1つ選択．上から順に判定する）

ボケを理解して面白さが分かるために，画像とボケの文の他に必要な知識である．
知識の段階は独立ではなく，必要な知識の量のグラデーションであるため，次の問いを上から順に確かめ，最初に「はい」となった段階とする．
固有名詞を言い当てられるかは判断する者（人やモデル）の知識に依存するため，名前を言えるかではなく，どの種類の情報が必要かで判断する．

1. 見た目だけ：画像に写っている見た目（表情，姿勢，状況）と，ボケの文の字面だけで面白さが分かるか．
2. 一般常識：誰もが知る言葉，慣用句，ことわざ，ダジャレの元の語，日常の事物や行事（ラジオ体操，だるまさんがころんだ）の知識を加えれば分かるか．
3. 画像中のオブジェクトの情報：画像に写っている，または画像中の文字（お題文，看板，題名など）で名指しされた特定の人物・キャラクター・作品・商品の情報が必要か．
   例：政治家の写真に，その人の有名な発言を改変したボケ．お題文「「サザエさん」最終回のタイトルとは？」に，登場人物の設定を使った回答．
4. 画像外のオブジェクト・事象の情報：上のいずれでもなく，画像に写っておらず文字でも示されていない特定の作品，番組，歌，CM，人物，地名，
   時事，ボケての機能などの知識が必要である．

## 4. 画像中の文字への依存（はい／いいえ）

ボケの意味や面白さが，画像中の文字（お題文，穴埋めの文，字幕，看板，漫画の台詞，カルタの札の文字そのものへの言及）を読まないと分からない場合に「はい」とする．
カルタの札のひらがなで始まることだけでは「はい」としない．

## 改訂履歴

- 第2版：性的・不適切の項目を除いた．必要な知識を，上から順に判定する手順として定義し直した．
- 第1版：report_019 の試験的な区分をもとに作成した．検証データのラベルの見直しの際に，画像中の文字で名指しされた対象と，一般常識と画像外の知識の境界を明確にした．必要な知識は，固有名詞を言い当てられるかに依存しないよう，画像中のオブジェクトの情報と画像外の情報で分けた．
