# Order 033

## ユーザーの指示（原文）

デバックモードを追加してほしくて、オンの時はブロックして解除すると新規のユーザーとしての処理をしてほしい
オフの時はこれまで通りに途中から再開で良いです

## 指示の解釈

- BoketeImageAnnotator に，Worker の変数 `DEBUG` で切り替えるデバッグモードを追加する（既定はオフ）．
- オンのとき，友だち追加のイベント（ブロックの解除を含む）を受けたら，その評価者の回答を削除し（問題の回答数も戻す），属性・回答数・注意確認の成績などを初期化して，新規の評価者と同じく，あいさつと同意の確認から始める．
  回答を残すと動作の確認の回答が集計に混ざり，同じ問題が再び出なくなるため，回答も削除する．古い吹き出しのボタンを見分ける出題の通し番号は初期化しない．
- オフのときは従来通り，「おかえりなさい」と続きの問題を示す．
- クイックトンネルの起動のスクリプトに `--debug` を追加して，オンで起動できるようにする（`.dev.vars` に `DEBUG=true` を書いてもよい）．
- 模擬試験に，オフでの再開とオンでの初期化の確認を加える．
