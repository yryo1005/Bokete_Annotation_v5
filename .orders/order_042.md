## 指示の解釈

report_041 の末尾の「次の候補」の3項目を全て実施する．

1. お題文ありの正例を増やした評価用データでの検証と，目視のラベルの再現性の測定
   - 既存の目視のラベル（1,020枚）と ex024 の教師ラベル（4.5万枚）に含まれない代表の画像から，層別抽出で新しい評価用データ（約420枚）を作る．層は現在のパッケージの形式・確認の質問の回答・お題文ありの生徒の確率で分け，お題文ありの正例が約200枚になるよう配分する．実データの値は層の重み（逆抽出確率）で推定する．
   - 1,020枚の評価で確認の質問（verify）が偽と答えた画像がなく，確認の質問の効果を測れなかったため，確認の質問が偽と答えた画像の層を設ける．
   - Claude Code が定義書 v5 の案に従い，予測を見ずに目視でお題文ありを付ける．
   - 再現性：既存の1,020枚から約90枚を同じ表に予測・過去のラベルを伏せて混ぜ，付け直したラベルと過去のラベルの一致率・Cohen の κ を求める（同じ付与者による再付与の一致であり，付与者間の一致ではない）．
   - 構成（現在のパッケージ，推奨の構成（確認の質問あり・なし），生徒単独など）の適合率・再現率・F1 と 95% 信頼区間を比べる．
2. 推奨の構成のパッケージへの組み込み（Bokete_Annotation_programs_v5.0）
   - お題文ありの生徒（ex024 の emb+probs，lr 1e-3，3 seed）を models/ に加え，属性 has_odai_text を出力する．
   - 形式は属性から導く（カルタ記号あり → カルタ，空欄あり → 穴埋め，お題文あり → お題文，それ以外 → 通常）．
   - 確認の質問の要否は1の結果で決める．
   - 全データの予測は保存済みの埋め込みから計算し直す（画像の読み直しはしない）．テスト，docs，README を更新する．
3. 定義書 v5 の確定
   - 1の付与で迷った境界の例を反映し，パッケージの docs/label_definition.md を第5版にする．
