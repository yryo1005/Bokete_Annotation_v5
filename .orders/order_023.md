# Order 023

## ユーザーの指示（原文）

画像外の知識を必要とするかを判定するF1と，6区分の判定精度を0．8以上に高めたい

画像外の知識が必要か判定するのに画像を使わないのはナンセンスな気がするので，小さなVLMを用いる方針が良い気がする
Qwenに限らずいろんなモデルを試し，精度と速度をまとめる

## 指示の解釈

- 目標：検証データ（620件の目視ラベル）の最終評価用（test）で，画像外の知識の F1 と発話の型6区分のマクロ F1 をそれぞれ0.8以上にする．
  目標に届かない場合は，届かない理由（教師ラベルの精度，目視のラベルの揺れなど）を定量的に示す．
- 9,250万件のボケに適用する判定器を，画像を入力しない生徒（文の埋め込みの MLP）から，お題画像とボケの両方を入力する小さな VLM に変える．
- Qwen 以外の小さな VLM（InternVL3.5，Gemma 3，SmolVLM2，LFM2-VL，MiniCPM-V など）も含めて，次の2通りで精度と速度を比べる．
  - そのまま指示で判定させる（ゼロショット）
  - 教師ラベルで微調整する（VLM の最後の隠れ状態に分類の出力層を付け，生成せずに1回の順伝播で判定する）
- 速度は，9,250万件に適用できるかの判断のため，1秒あたりの処理件数と全件の推定時間で示す．
- 生徒は教師ラベルの精度を超えにくいため，学習の信号も改善する．
  - 教師の改善：推論（thinking）モデル，複数モデルの多数決など
  - 目視のラベルの利用：調整用の目視ラベルによる追加の微調整（調整用と最終評価用を入れ替える2分割で評価）
  - 目視のラベルの揺れの上限：一部の検証データを見直さずに付け直し，一致率を測る
- 実験は programs/ex016_boke_small_vlm/ で行い，Bokete_Annotation_programs_v5.0/ には含めない（試作）．
