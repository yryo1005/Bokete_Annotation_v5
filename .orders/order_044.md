# Order 044

## ユーザーの指示（原文）

この案で実施してください

（直前の議論で合意した案：お題文ありを投稿者の意図で決める定義をやめ，「文字あり」を，見て決められる文の属性に細分化する．属性は軸A（文字の層：場面の文字，吹き出し，重ねた文字，余白の文字）と軸B（重ねた文字と余白の文字の文の形：問い，指示，題目の句，その他の文）とし，お題文ありは規則で導く．）

## 指示の解釈

- 定義書 v6 の草案（文の属性）を書く．誰が書いたか・題のつもりか・既存の歌詞の引用かは記録しない．
  - 議論の後に詰めた点：空欄を含む文（v5 で除いていたもの）を軸Bの形「空欄を含む文」として分ける．透かし・ロゴ・著作権表示・日付・ボケてのテンプレートの定型の見出しは「場面の文字」に含める．画面のスクリーンショットの文字は場面の文字とする．軸Bは層ごと（重ねた文字／余白の文字）に記録し，組の情報が失われる頻度を数えられるようにする．
- 生徒で学べるかを確かめる実験を行う（パッケージは変更しない）．
  1. 既存の目視のラベル付きの画像（ex024 の1,020枚，ex025 の新しい評価用データ420枚，order_043 の追加180枚の計1,620枚）に，予測を伏せて v6 の属性を目視で付ける．
  2. Qwen3-VL-32B に v6 の属性と，重ねた文字・余白の文字の書き起こしを問い，教師としての精度を測る．
  3. 軸Aは画像の埋め込み（SigLIP2）の分類器を交差検証して，属性ごとの精度を測る．
  4. 軸Bは，画像の埋め込みの分類器と，書き起こした文の分類器（文字 n-gram，文の埋め込み）を比べる．軽い OCR（yomitoku）や小さな VLM の書き起こしの速さと精度も測る．
  5. v6 の属性から導いたお題文ありと v5 の目視のラベルの差（定義の変化）と，導いたお題文ありの精度を，層の重みで推定する．
