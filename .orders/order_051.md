# Order 051

## ユーザーの指示（原文）

最終盤の構成を
画像のアノテーション，大喜利のアノテーションについてそれぞれ精度（F1、再現率，適合率）やプロンプト，分類方法をまとめて

## 指示の解釈

アノテーションを現段階で止めることを前提に，最終版（パッケージ Bokete_Annotation_programs_v5.0 の v5.3.0．ボケの段階は v5.2.0）の構成をまとめる．

- 画像のアノテーション（形式・属性・媒体・お題文あり・キャプション）と，大喜利（ボケ）のアノテーション（発話の型・画像外の知識・制約の順守・画像中の文字への依存）のそれぞれについて，次を記す．
  - 分類の方法（教師のモデルと指示，生徒のモデル，後処理と規則）
  - 指示（プロンプト）の本文
  - 精度（適合率・再現率・F1．実データの推定と評価用データ．出典の実験とレポート）
- 新しい実験は行わず，既存のプログラムと出力，レポート（report_012〜050）から値を集める．値はできるだけ出力のファイルから読み直して確かめる．
- 結果を report_051 にまとめる（PDF も作る）．document.md にはレポートの場所を加える．
