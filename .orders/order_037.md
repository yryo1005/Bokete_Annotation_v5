# Order 037

## ユーザーの指示（原文）

（直前の質問）属性や形式、媒体のそれぞれのカテゴリの定義と例をA4 1ページに収めた紙があったら答えやすいかな

試しにA4 1ページのものと2ページのものを作ってみて

## 指示の解釈

- 形式，画像の要素（属性），媒体の各ラベルの定義と実例の画像をまとめた，評価者に配る早見表を A4 の PDF で試作する．1ページ版と2ページ版の2種類を作る．
- 文言は Bot の表示（`src/labels.ts`，表示の版4）と同じものを自動で読み込み，実例の画像は説明のカルーセルと同じ画像を用いる．画像の要素の「どれもなし」には，3者のアノテーターがどれもなしとした画像を1枚選んで用いる．
- 紛らわしい組み合わせ（形式の優先の順，形式と画像の要素の違い，テキストグラフィックに当たらない例，一致しないの基準）の注意を載せる．
- LINE の「早見表」コマンドなどの配布の方法は今回は実装せず，試作の確認後に決める．
