# Order 009

## ユーザーの指示（原文）

F_v2 の構成と英語の文体を保ったまま，text の定義のみを定義書 v2 に合わせる（「投稿者が重畳した問いや指示の文がある．絵や写真があってもよい」）

合成画像とその他の文字を，生徒の学習の重み付けの対象から外す．または，合成画像の判定を「境界線で区切られた複数の写真や絵があるか」のような観測しやすい問いに置き換える

絵画と CG を独立の質問に分け，「画家が描いた美術作品か」「3DCG ソフトや生成 AI で作られたか」のように問う

お題文の判定に，文字の位置と体裁（テンプレートの枠，画像の上下の帯，無地の背景）を明示的に問う補助の質問を加える

上記は実施して良いです
また，プロンプトが英語の方が性能が向上する場合，英語に変更して良いです

現状の蒸留モデルで実際に実データにアノテーションし，
少ないカテゴリのデータを抽出し，これを評価用として加え，
評価の確信度を上げたいと思います．
（ClaudeCodeがアノテーション済みからCGや絵画等の少ないカテゴリのデータを目視で確認する
これに同意するか否かを質問で出してください．

（質問への回答）同意（偏り対策込み）：モデルが少ない区分と判定した画像に加え，確率がしきい値付近の画像と無作為の画像も混ぜて目視する．

## 指示の解釈

- report_008 の改善案のうち4つ（形式のプロンプトの定義の修正，合成画像の問い方と重み付けの対象の変更，絵画と CG の独立の質問，お題文の体裁を問う補助の質問）を実装し，比較する．各プロンプトは英語版も作り，日本語版より良ければ英語を採用する．
- 評価用データの拡充：ex005 の最良の蒸留モデル（微調整した SigLIP2-B，追加分あり・重み付き）で，これまで使っていない実データ（収集の候補30万枚から既に使った画像を除いたもの）にアノテーションする．少ない区分（ゲーム，CG，絵画，カルタ）ごとに，「モデルが判定した画像」「確率がしきい値付近の画像」から層別に抽出し，さらに全体から無作為に抽出した画像を加えて，計約600枚を Claude Code が目視でラベル付けする．report_007 の200枚と合わせて，少ない区分の評価用データとする．層別の抽出確率で重み付けすることで，適合率に加えて再現率も推定する．
- プロンプトの選択による楽観を避けるため，少ない区分の評価用データも調整用と最終評価用に分ける．最終評価用データ（通常の test 320枚と，少ない区分の最終評価用）はプロンプトの選択に用いない．
- 実験番号は ex005 の続き（教師データと損失の変更は軽微な変更）として ex005b とし，結果は outputs/ex005_rare_weighted_distill/ 以下に条件名を変えて保存する．
