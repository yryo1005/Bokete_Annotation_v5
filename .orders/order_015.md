# Order 015

## ユーザーの指示（原文）

次に写真（現実画像）のキャプションを生成することを考えます
この際，詳細なキャプションを生成するというよりは，画像の概要がわかる程度の粒度を考えています

何パターンかキャプションを生成する方法を考え，速度と精度で比較してください

なおこれは試作段階なので、Bokete_Annotation_programs_v5.0は編集しないでください

## 指示の解釈

- 対象：order_014 のアノテーションで媒体が写真のみのお題画像（約350万枚）．
- キャプション：日本語の1文（30〜60字程度）で，画像の概要（誰・何が，どこで，何をしているか）がわかる粒度とする．細部や推測（感情の理由など）は求めない．
- 方法の比較：複数の方式（VLM の大きさ・入力解像度・指示の仕方，VLM のキャプションの近傍の検索による高速化，など）でキャプションを生成し，
  速度（全写真の処理時間に換算）と精度を比較する．
- 精度：写真の評価用データ（無作為抽出）に Claude Code が参照キャプションを付け，(1) より大きな VLM による採点（画像・参照・候補を与える），
  (2) Claude Code の目視による誤りの判定（一部），(3) 参照との意味的な類似度で評価する．採点者と目視の一致も確かめる．
- 試作のため，研究用のリポジトリ（programs/ex010_photo_caption）で行い，Bokete_Annotation_programs_v5.0/ は編集しない（結果の読み込みのみ）．
- 実験番号は ex010 とする．
