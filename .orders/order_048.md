## 指示の解釈

直前の回答で提案した独立な評価用データによる検証を，人の代わりに Claude Code が目視のラベルを付けて実施する．

- 実験は新しい通し番号 ex028 とし，プログラムは `programs/ex028_odai_holdout/`，データは `datasets/ex028_odai_holdout/`，出力は `outputs/ex028_odai_holdout/` に置く．
- 画像：ex026 の1,620枚，ex024 の教師ラベルの画像，ex027 の教師ラベルのプール（3万枚）に含まれない代表の画像から，ex025 の評価の層（A〜D，F と，通常と予測した画像の p の区間 N0〜N3 の9層）ごとに無作為に抽出する．枚数は上限の600枚とし，層ごとの割り当ては ex025 の600枚と同じにする．
- 判断のずれを確かめるため，ex026 の1,620枚から36枚を再び混ぜ，番号だけを付けた一覧で目視する（予測や過去のラベルは見ない）．
- ラベルは定義書 v6 の書式（文字の層と文の形）で付け，既定の規則 R1b でお題文ありを導く．
- 比べる構成：v5.3.0 単体と，後段（ex027 の「v5.3.0 の確率＋埋め込み」のロジスティック回帰を1,620枚の全てで学習したもの）．参考として ex027 で最も高かった「v5.3.0 の確率＋32B の書き起こし」も比べる（600枚に Qwen3-VL-32B の書き起こしを付ける）．
- 判断の基準：全データの推定の F1 の差の95% 区間（層ごとの復元抽出）が0を超えれば後段を採用し，0を含めば v5.3.0 単体のままとする．
- 結果を report_048 にまとめ，document.md と visualize_result.ipynb を更新する．
