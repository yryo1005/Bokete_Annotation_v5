# Order 032

## ユーザーの指示（原文）

無事動作しました
とりあえず私が30件回答してみたのですが一致度はどんなもんですか？
確信度が高い結果を得るのに何人が何件回答しないといけないか考えてください

（貼り付けられた修正の要望）
↑実例　の文字を消す

画像が縦に長いと画面外に見切れる場合があるので，
白地に画像を貼り付け横長の画像にし，画面内に収まるようにする

属性を，
空欄あり　○/×
カルタ記号あり　○/×
文字あり　○/×
と表示すると誤解されそうだから
「属性なし」，「空欄あり」，「文字あり＋カルタ記号あり」
のように媒体と同じような表現にする

## 指示の解釈

- BoketeImageAnnotator のクイックトンネルでの運用（ローカルの D1）に記録された，ユーザー自身の回答（約30件）を集計し，アノテーター（Claude Code，Qwen，生徒モデル）×軸ごとの一致率を示す．件数が少ないため，Wilson の95%区間で不確かさも示す．
- 確信度の高い結果に必要な回答数を検討する．アノテーター×軸ごとの一致率を所定の精度（95%区間の半幅）で推定するのに必要な回答数，問題ごとに複数人の多数決で正解を決める場合の必要な人数，評価者間の一致の確認を考え，評価者の人数×1人あたりの回答数の組み合わせとして示す．試行の回答の一致率を前提の値に用いる．
- Bot の表示を次の通り修正する．
  - 説明のカルーセルの「↑実例」の文字を消す．
  - 縦長の画像が画面外に見切れないよう，白地の横長の画像に貼り付けて配信する（画像の生成の段階で行う）．
  - 属性の値を「空欄あり ○/×」等の3行の表示から，「属性なし」「空欄あり」「文字あり＋カルタ記号あり」のような，媒体と同様の1つの表現に変える．
- 既存の回答（ローカルの D1）は消さない．修正後の Bot は，動作中の wrangler dev に反映されることを確かめる．
