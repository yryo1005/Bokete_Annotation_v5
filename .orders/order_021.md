# Order 021

## ユーザーの指示（原文）

不適切判定は取り除く

形式の判定は，カルタの判定が容易なのはわかるけど，
お題文・空欄に従っているかはどう判定する？
これは次回のレポートに書いてください

発話の型について，
教師ラベルを水増しして，
少ない発話の型のデータの比率を増やす
また，ClaudeCodeのアノテーションした検証データも増やす
同様に，カテゴリの区分についても検討する

必要な知識について，
下記の定義が適切であるか，改めて考える
0 見た目だけで分かる
G 一般常識
I 画像中のオブジェクトの情報が必要
O 画像外のオブジェクト・事象の情報が必要
独立というよりはグラデーションな気がするので，
上から順に判定していくと良いかもしれない
MeCab等の形態素解析ツールを用い，
品詞を入力に加えると判定が改善する？
0とGが混同されるなら，
ユースケース的には同じクラスにまとめても良いかもしれない

## 指示の解釈

- 性的・不適切の項目を定義書と評価から除く（定義書 第2版）．
- 穴埋め・お題文の制約の順守の判定方法を検討し，検証してレポートに書く．自然な違反はまれなため，ボケを同じ形式の別のお題に付け替えた
  「入れ替えの組」を違反の代わりとして，判別の精度（AUC）を測る．方法は，VLM の教師の判定，お題の文の書き起こしとボケの文の埋め込みの類似度，
  画像とボケの埋め込みから組の正否を学習する分類器（入れ替えの組で自己教師的に学習）を比べる．
- 発話の型：(1) 教師ラベルの水増し：少ない型（心の声，ツッコミ，状況の説明，名付け・見立て）の候補を規則と教師の予測で多めに集め，
  発話の型の精度が最も高い教師（32B）でラベルを付けて学習データの型の比率を均す．(2) 検証データの追加：少ない型が多く含まれるように抽出したボケに
  Claude Code が予測を見ずにラベルを付け，検証データを増やす．(3) 区分の検討：型を統合した区分（例：登場人物の言葉＝セリフ＋心の声）での精度を比べる．
- 必要な知識：(1) 上から順に判定する方法（見た目だけで分かるか→一般常識で分かるか→画像中の対象の情報か→画像外の情報か）を教師の指示として試す．
  (2) 形態素解析（MeCab，fugashi＋UniDic）の品詞（固有名詞など）を生徒の入力に加える．(3) 0 と G を統合した3区分での精度を比べ，定義の適否を検討する．
- 研究用のリポジトリ（programs/ex014_boke_labels_v2）で行い，Bokete_Annotation_programs_v5.0/ には含めない．
