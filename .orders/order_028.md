# Order 028

## ユーザーの指示（原文）

画像と大喜利についてClaude Codeがアノテーションしたデータの例を層ごとにレポートにまとめて

## 指示の解釈

- 「Claude Code がアノテーションしたデータ」は，Claude Code が画像を見て目視で付けたラベルとする．新たなアノテーションはしない．
- 「層」は，目視のラベルを付けるデータを抽出したときの層（層別抽出の層）とする．
  - お題画像：ex008 の実データの層別抽出220枚（定義書 v4．生徒の予測で11層に分け，各層20枚）．
  - 大喜利（ボケ）：ex013/ex014 の検証データ620件（お題のラベルで7層に分けた420件と，少ない発話の型の候補で抽出した200件）．
    ラベルは最終の合意ラベル（ex016 の consensus_labels.txt．発話の型と画像外の知識）と，ex013/ex014 のラベル（制約の順守，必要な知識，画像中の文字への依存）を示す．
- 層ごとに，件数とラベルの分布，数件の例（画像とラベル，ボケの文）を図と表で示す．
- 例を集めて図を作るスクリプトを programs/ex021_annotation_examples/ に置き，結果を .reports/report_028.md と PDF にまとめる．
