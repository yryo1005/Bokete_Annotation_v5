# Order 003

## ユーザーの指示（原文）

ラベルを厳密化する際の案を考えてください

## 指示の解釈

- report_002 で，強い手法と目視ラベルが食い違う画像の多くが「文章のお題」「文字を含む画像」「穴埋め」「カルタ」の境界や，画風の境界（イラスト・漫画・アニメ・写真）にあることが分かった．本 Order は，その曖昧さを解消するためのラベル定義（アノテーションの指針）の改訂案を作ることである．
- 成果物は案（設計）であり，新しい定義による全件の付け直しや実験は含まない．ただし案を具体的にするため，既存の評価用データ（640枚）と各手法の予測から，判断の分かれる実際の画像を抽出して例として示す．
- 案は，ボケの生成に必要な処理（文字の読み取り，記号の位置の検出，事前知識）から逆算して定義を決める方針とし，複数の選択肢（現行の7クラスを保つ案，多ラベル化する案など）を比較したうえで推奨を示す．
- 定義の改訂を評価用ラベル・VLM のプロンプトに反映し，一致度で検証する手順も併せて提案する．
