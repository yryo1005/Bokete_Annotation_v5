# Order 012

## ユーザーの指示（原文）

ロゴ等も含めて文字がある画像は文字ありとする（定義Aの採用
文字が大喜利に影響しているかは，文章を見て判断する
ただし，形式のお題文は維持する

重みつけ損失を廃止する

お題文の過検出を防止するため「画像に元からある看板や字幕を除く」などのプロンプトを追加する

目視ラベルを追加し，評価の厳密さを向上させる
この際，現状の生徒の予測に基づき各形式，媒体，属性の分布が一様になるように目視ラベルを振り，これを用いて評価すると良い

## 指示の解釈

- report_011 の案Aを採用し，定義書を第4版とする．属性の「文字あり」は，ロゴ・透かし・著作権表示・看板・衣服の文字も含め，読める文字があれば真とする．文字が大喜利に影響しているかは，画像のラベルでは扱わず，ボケの文章を見る後段の処理で判断する（定義書に明記する）．形式のお題文は維持する．
- 重み付き損失を廃止し，生徒は重みなし（少ない区分の追加あり）のみとする．
- 形式のプロンプト F_v2 に「画像に元からある看板，字幕，歌詞，図表の文字はお題文ではない」等の規則を加えた F_v9 を作り，Qwen3-VL-8B で評価用データ・少ない区分の評価用データ・教師ラベル用の4万枚と追加分に適用する．F_v2 と比べ，良い方を教師に採用する．
- 目視ラベルの追加：現状の最良の生徒（ex007 の T_v8m・base+rare・重みなし，seed 0）の実データへの予測に基づき，形式4・属性3・媒体7の各クラスに予測された画像を同数ずつ（各20枚程度）層別に抽出し，Claude Code が予測を見ずに定義書 v4 でラベルを付ける．
- 既存の目視ラベルのうち「文字あり」は定義 A に合わせて見直す（評価用データ640枚と実データ160枚の文字なしの画像）．
- 評価：通常の評価用データ，少ない区分の評価用データ，実データ（無作為160枚と層別抽出）で教師と生徒を評価する．層別抽出の集計は，クラスごとの精度と，抽出確率の逆数で重み付けした実際の分布での推定値の両方を示す．
- 実験番号は ex008 とする．
