# Order 019

## ユーザーの指示（原文）

ここから大喜利をアノテーションすることを考えます

大喜利は
・画像のオブジェクトについての知識に基づく
・画像のオブジェクトについての知識に基づかない

・カルタ記号に書かれたひらがなからはじまる
・お題文に従う
・画像中の文字に基づく
と言ったパターンが考えられると思います

いくつかのサンプルから，
そもそも大喜利をどう区別するべきかを例を交えてレポートにしてください

下流のタスクである大喜利生成や大喜利判定を意識してください

## 指示の解釈

- 対象は，お題画像に投稿された大喜利（ボケの文章）である．お題画像のラベル（BoketeDBv5 の形式・属性・媒体・キャプション）を前提に，ボケをどう区別するべきかの設計を検討する．
- BoketeDBv4 のボケと BoketeDBv5 のアノテーション（読み込みのみ）から，形式・媒体・文字の有無が異なるお題を層別に抽出し，評価の高いボケと無作為のボケを
  画像と並べて目視で読み，ユーザーの挙げた観点（知識の有無，カルタ，お題文，画像中の文字）が実際のボケでどう現れるかを確かめる．
- 抽出したボケに Claude Code が試験的に分類を付け，各区分の割合，区分の判断のしやすさ，ボケだけで判断できるか（画像やお題のラベルが要るか）を調べる．
- 大喜利の生成（条件付けの単位，データの絞り込み）と判定（評価の基準，誤りの区別）にとって有用な区分を提案し，例を交えてレポートにまとめる．
  本指示は設計のレポートであり，大規模なアノテーションの実装は行わない．
- 実験番号は ex012 とする．Bokete_Annotation_programs_v5.0/ は編集しない．
