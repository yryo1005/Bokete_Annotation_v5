# Order 041

## ユーザーの指示（原文）

属性（カルタ記号あり，空欄あり，お題文あり，文字あり）を複数
属性（写真，アニメ，マンガ，テキストグラフィック，絵画，ゲーム，イラスト）を複数
形式は属性から逆算
の構成で行こうと思います

ただ，現状のお題文の判断精度が低いので，Qwenのプロンプトを変更する等で精度を改善してください

## 指示の解釈

- お題画像のラベルの構成を次に改める方針とする（定義書 v5 の案を作る）．
  - 属性（複数選択）：カルタ記号あり，空欄あり，お題文あり，文字あり．
  - 媒体（複数選択．2行目の「属性」は媒体と解釈する）：写真，アニメ，マンガ，テキストグラフィック，絵画，ゲーム，イラスト（現行の7項目と同じ）．
  - 形式は属性から逆算する：カルタ記号あり→カルタ，空欄あり→穴埋め，お題文あり→お題文，それ以外→通常（定義書 v4 の優先順位と同じ）．
- 本オーダーの主題は「お題文あり」の判定精度の改善である．
  - 「お題文あり」は，空欄やカルタ記号の有無と独立に付ける．空欄を含む文そのものはお題文としない（定義書 v4 の規則を引き継ぐ）．
  - 正解：目視のラベル1,020枚のうち，形式がお題文の画像はお題文あり，通常の画像はお題文なしとし，穴埋めとカルタの画像（328枚）に Claude Code が目視でお題文ありを付け直す．
  - Qwen の指示（プロンプト）やモデルを変えて，「お題文あり」の判定の適合率・再現率・F1 を比べる．調整は評価用データの調整用の集合で行い，最終評価用の集合と実データ（重み付きの推定）で報告する．
  - 処理時間を考慮し，生徒の予測で質問の対象を絞る段階的な構成（全プロセス）の精度と，全データでの処理時間の見積もりも示す．
- パッケージへの組み込み（生徒の出力層の変更と学習し直し，全データの予測し直し）は，本オーダーの結果を見て次のオーダーで行う．
- プログラムは programs/ex024_odaibun_attr/，結果は outputs/ex024_odaibun_attr/ に置き，report_041 と PDF にまとめる．
