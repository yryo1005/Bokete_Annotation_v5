# Order 050

## ユーザーの指示（原文）

写真文字なしと写真で通常がそれぞれどれくらいあるかとその判定精度を出して

## 指示の解釈

現実画像に対する大喜利の面白さ判定に向けて，お題画像を絞り込む2つの条件について，全データでの件数と判定精度を求める．

- 条件A「写真・文字なし」：パッケージ v5.3.0 の媒体が写真のみ（他の媒体を含まない）で，文字ありが偽．
- 条件B「写真・通常」：媒体が写真のみで，形式が通常（お題文・穴埋め・カルタでない）．
- 件数：代表の画像の数と，全てのお題（重複を含む）の数．あわせてボケの件数も求める．
- 判定精度：これまでの目視のラベル（媒体・文字あり・形式）がある画像で，条件ごとの適合率・再現率・F1 を求める．層別の抽出の場合は全データへの重みを用いる．
- 実験は ex029 とし，結果を report_050 にまとめ，document.md と visualize_result.ipynb を更新する．
