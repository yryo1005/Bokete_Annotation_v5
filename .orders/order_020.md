# Order 020

## ユーザーの指示（原文）

お題の形式と大喜利が一致しているかを評価するのは良いと思う

画像に写る固有の対象の同定
ここでいう同定は，対象の人物等の名前を出力すること？

知識は
・見た目だけ
・一般常識
・画像中のオブジェクトの情報を必要とする
・画像外のオブジェクト・事象の情報を必要とする
ことがわかれば良い気がする
（固有名詞を推定できるかはモデルに依存すると思うため

発話の肩を6種に分けるのは良いと思う

性的・不適切も弾けると良い

1. 定義書の作成：本稿の区分（発話の型，必要な知識，画像中の文字への依存，制約の順守）の定義書を作る．
もう少し層ごとにサンプルを抽出し，確度の高い検証データを作ってください

3. 自動判定とラベル付け：制約の順守を規則で自動判定する．発話の型と知識は，お題のアノテーションと同じく，
VLM の教師と生徒の蒸留で付けられるかを確かめる．ボケは約 9,250 万件ある．このため，全件に VLM を適用
するのは現実的でない．
よって単純なアルゴリズムや蒸留モデル等のアプローチを複数考えて，検証してください

この検証は最終版ではないのでBokete_Annotation_programs_v5.0には含めないでください

## 指示の解釈

- 質問（同定）への回答：report_019 の E は「名前を出力すること」ではなく，「写っている特定の対象が何かを知っていないとボケが理解できない」ことを指していた．
  ユーザーの提案どおり，知識の軸を「見た目だけ／一般常識／画像中のオブジェクトの情報が必要／画像外のオブジェクト・事象の情報が必要」の4段階とし，
  モデルが固有名詞を出せるかには依存しない定義にする．
- ボケの定義書 第1版を作る：制約の順守（形式と一致しているか），発話の型（6種），必要な知識（4段階），画像中の文字への依存，性的・不適切．
- 検証データ：report_019 の140件に加え，層ごとにお題とボケを追加で抽出し（計約420件），定義書に従って Claude Code が目視でラベルを付ける．
  調整用（dev）と最終評価用（test）にお題の単位で分ける．
- 方法の比較（ボケ約9,250万件に適用できるもの）：
  - 規則：カルタの制約の順守（書き出しのかなとお題の札のかな），発話の型の表層の手がかり（括弧，文末，「〜の時の俺」など），不適切な語の辞書．
  - VLM の教師：Qwen3-VL（30B-A3B，8B，32B）に画像・お題の形式・ボケを与えて全ラベルを問い，検証データで精度を比べる．
  - 蒸留した生徒：教師で数万件のボケにラベルを付け，ボケの文の埋め込み（テキストの埋め込みモデル），お題の画像の埋め込み（v5.0 の保存済みのもの，読み込みのみ），
    お題の形式などを入力とする分類器を学習し，速度と精度を比べる．
- 研究用のリポジトリ（programs/ex013_boke_labels）で行い，Bokete_Annotation_programs_v5.0/ には含めない．
